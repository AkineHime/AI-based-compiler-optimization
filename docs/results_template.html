Which optimizations should a compiler run? We timed every option to find out.

This project is a complete compiler for MiniC, a small C dialect, with six optimization passes you can switch on and off. That's 64 combinations. We compiled programs with every combination, timed each real binary, and trained a model to predict the best combination without running the program.

01 · How it works

From source code to a measured speedup

Every program goes through the same pipeline. The compiler turns MiniC into three-address code (TAC), a simple instruction list where each line does one operation. The optimization passes rewrite the TAC. It is then turned back into C and compiled with gcc -O0, which tells gcc not to optimize, so any speedup comes from our passes alone.

05 · Why it's hard

  
Passes don't add up. They interact.

  
If each pass worked independently, you could predict the all-on speedup by multiplying the
    single-pass speedups together. You can't: passes create work for each other. For example, constant folding and
    CSE leave behind dead code that only DCE removes.

  

    

      

    
Measurement noise

      
same binary, 15 runs, 8 programs timed in parallel

      
      
So every timing is the fastest of 15 runs (the least disturbed one), after 4 warm-up runs.

07 · Method

  
How the numbers were measured

  

    
Correct first
A build only counts if it returns exactly what the unoptimized build returns. A miscompiled combination adds no data.

    
gcc -O0
gcc's own optimizer is off, so the speedups come from the MiniC passes, not from gcc.

    
Fastest of 15
4 warm-up runs, then the minimum of 15 timed runs: the run least disturbed by everything else on the machine.

    
No leakage
The model is tested with whole programs held out (GroupKFold), so it never sees a program it's scored on.

  







  
08 · Run it yourself

  
Every number here can be reproduced

  
Needs Python 3.9+ and gcc. From the repository folder:

  

    
1 · Install and check your setup
pip install -r requirements.txt
python minic.py check

    
2 · Compile a program with all passes and run it
python minic.py compile canonical_example.mc --optimize 63 --run

    
3 · Ask the model, then prove it on the clock
python minic.py recommend benchmarks/loops/licm_arith.mc --verify

    
4 · Open the browser playground
python minic.py playground

    
Rebuild this page
python minic.py results

    
Re-time all 57,600 builds (~3.5 hours)
python minic.py experiment --full
