MiniC Playground
source — MiniC

Write MiniC on the left and press Run. The program is compiled twice with gcc -O0 — once as-is, once with the pass combo the model recommends — then timed. MiniC has no I/O, so a program’s result is its return value.

Run a program to see the recommended passes, what each one changed, and the static features the model read.

Run a program to see its three-address code before and after optimization.
